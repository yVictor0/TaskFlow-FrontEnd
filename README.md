## 📌 Descrição do Projeto

O **TaskFlow FrontEnd** é a interface gráfica da plataforma TaskFlow, desenvolvida para proporcionar uma experiência fluida, moderna e intuitiva na gestão de tarefas diárias. A aplicação permite que os usuários criem, acompanhem e organizem suas rotinas com praticidade, integrada a uma API backend.

---

## 🚀 Tecnologias Utilizadas

* **React**: Biblioteca principal para construção da interface de usuário.
* **Vite**: Ferramenta de build rápida e servidor de desenvolvimento.
* **JavaScript (ES6+)**: Linguagem base do projeto.
* **CSS3 / Tailwind / Styled Components**: Estilização e layout responsivo.
* **ESLint**: Padronização e qualidade do código.
